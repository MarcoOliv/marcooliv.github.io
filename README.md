# marcooliv.github.io

Site público dos apps (políticas, termos, exclusão de conta). Os endereços são usados pela App Store e pelo Google Play:
`https://marcooliv.github.io/<app>/privacy-policy`, `/terms-of-use`, `/delete-account`.

**Não editar aqui.** A fonte é a pasta `docs/` de cada app (repositórios privados). Para atualizar: `tool/site_sync.sh` no repositório do app.
